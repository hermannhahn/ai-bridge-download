## 💻 Instruções de Instalação no Windows

1. Baixe o instalador [`AI-Bridge-Setup-v2.0.0.exe`](https://github.com/hermannhahn/ai-bridge-download/raw/main/AI-Bridge-Setup-v2.0.0.exe).
2. Execute o arquivo baixado como **Administrador**.
3. Siga o assistente de instalação para concluir a configuração do AI Bridge e do serviço de auto-atualização em segundo plano.
4. Inicie o sistema através do atalho criado na Área de Trabalho ou menu Iniciar.

### 🌟 Notas do Release v2.0.0:
- Migração completa para Go nativo com interface gráfica Desktop para Windows (Wails).
- Suporte a busca semântica vetorial em PostgreSQL (`pgvector`) e RAG local (`Ollama`).
- Gerenciador de ferramentas FastMCP e conector de WhatsApp (WAHA).
- Módulo de varredura assíncrona de sub-rede para dispositivos IoT.
- Módulo de Auto-Atualização (`updater.exe`) integrado.
